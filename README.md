# MAGTRACK: Subsystem Design Portfolio

MAGTRACK is a magnetic wall-climbing robot for external ultrasonic inspection
of large-diameter pipelines (DN1000+), built as the capstone project at
Higher Colleges of Technology by a 6-person team.

This repository documents my individual contributions:

| Project | My role | Status |
|---|---|---|
| [Scanning & Dosing Subsystem](scanning-dosing/) | Sole designer | Design complete (Rev 2); tests planned |
| [Power & Actuation PCB (Board 1)](pcb-power-actuation/) | Designed Board 1 | Layout finalized |

Board 2 (logic) was designed by a teammate and is not included here.

Results marked "planned" are test protocols that have not been run yet.
