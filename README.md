# MAGTRACK: Subsystem Design Portfolio

MAGTRACK is a magnetic wall-climbing robot for external ultrasonic
inspection of large-diameter pipelines (DN1000+), built as the
Capstone Design Project at Higher Colleges of Technology (6-person team).
